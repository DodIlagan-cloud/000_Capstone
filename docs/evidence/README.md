# Evidence

<!-- M0 Foundation: documentation lane for evidence guidance and indexes. -->

Use this folder for project-level evidence guidance or indexes when evidence spans modules.

All module and regression evidence must be stored under root `test-results/`.

Module/app folders are reserved for module-specific code, module-local automated tests, runtime configuration samples, local run instructions, and assets required by the module/app. Do not store final assessment evidence under `apps/<app>/test-results/` or `modules/<module>/test-results/`.

Screenshot evidence should use actual Windows browser or terminal captures when screenshots are required.
