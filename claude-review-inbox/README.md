# Claude Review Inbox

Drop Claude review notes for Codex here as Markdown or text files.

Suggested naming:

```text
round-06.md
round-07.md
```

Each review should include the finding severity, affected file/path, observed behavior, and suggested fix when available.

Codex automation will inspect the newest review files, verify findings against the code, implement confirmed fixes, run focused tests/builds, and report the result in the thread.
