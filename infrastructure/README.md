# Infrastructure

<!-- M0 Foundation: reserved boundary for deployment and environment assets. -->

Infrastructure work belongs here as the project reaches it:

- `compose/` for local multi-service orchestration.
- `containers/` for container assets shared across modules.
- `cloud/` for M14 cloud-readiness notes, environment configuration examples, secret boundaries, health checks, and deployment evidence expectations.

Module runtime behavior stays in its owning app or module folder.
